# LV Transfer

Сайт для моего трансфер-сервиса в Риме — LV Transfer. Возит людей из аэропортов Fiumicino и Ciampino, из круизного порта Чивитавеккья и по другим городам Италии.

## Что я сделала

Собрала сайт на React через Vite. Поставила React Router, чтобы переключаться между страницами без перезагрузки — сделала навбар и четыре раздела: главная, услуги, галерея и контакты.

На странице услуг вывела карточки с трансферами и добавила кнопки-фильтры по категориям — аэропорт, порт, межгород. Кнопки меняют, какие карточки показывать, через фильтрацию массива с данными.

На странице галереи сделала слайдер с фотографиями — переключается сам через несколько секунд, плюс можно листать вручную стрелками или точками внизу.

На странице контактов сделала форму бронирования. При отправке форма собирает данные (имя, телефон, дату) и открывает WhatsApp с уже готовым сообщением, чтобы клиенту оставалось только нажать отправить. Ниже — блок частых вопросов, сворачивается и разворачивается через Bootstrap.

Стили в основном взяла из Bootstrap, немного добавила своих через обычный CSS-файл.

## Как запустить

Ставлю зависимости и запускаю локальный сервер:

```
npm install
npm run dev
```

Собрать финальную версию для публикации:

```
npm run build
```
